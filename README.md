# Desktop Pet（螢幕小桌寵）

這是一個純粹做來自己玩、圖個輕鬆開心的趣味小專案。

牠是一隻常駐在 Windows 螢幕角落的透明浮動小掛件，平時乖乖停靠在工作列或螢幕邊緣，陪著你一邊寫代碼一邊發呆。小傢伙手裡拿著一塊小平板，即時幫你盯緊各家 AI 模型的 API 餘額，免得寫代碼寫得太投入一不小心荷包失血破產。

---

## 怎麼玩

- 看緊錢包：手中小平板支援串接 DeepSeek、Claude、OpenAI 與 Gemini。每當呼叫 API 扣款時，小傢伙就會挨揍受擊晃動；當帳戶充值時，大碗米飯盆會從螢幕上方掉落下來，用滑鼠拖過去餵牠吃個飽。要是懶得餵，掉落一會兒牠還會自己開啟雷達吸進去吃。
- 摸頭與戴鐵盆：無聊或代碼寫不出來時，用滑鼠游標在牠頭上來回撫摸可以摸摸頭安撫。吃完飯彈出的空鐵盆，還能順手拖去扣在牠頭頂當防禦頭盔；戴上鐵盆後小傢伙表情會變得一臉冷淡且摸頭無效，對著頭部連點兩下就能把鐵盆敲下來。
- 語音聊天與吐槽：打開簡約對話小視窗，可以用打字或語音跟牠閒聊吐槽，回覆還會在小傢伙頭頂冒出動態對話氣泡。
- 隨意換角色：內建 DeepSeek、Claude、Gemini、GPT 等立繪，也支援匯入自己喜歡的角色圖片，甚至可以在螢幕上召喚多隻小傢伙一起陪你。

## 專案目錄與版本

本專案主要以 Windows 為主，同時保留其他實驗版本：

- windows/：Windows 平台專案目錄。
  - python/：推薦使用的主力重構版（基於 Python 3.10+ 與 PySide6），順暢省電、物理碰撞完整。
  - powershell/：早期免安裝 Python 環境的單純腳本備用版。
- dsh-balance-pet-macos/：macOS 平台原生版（Swift + AppKit）。
- integration/：可嵌入個人網頁或監控面板的純 JavaScript 組件。

---

## 怎麼跑起來（快速開始）

推薦直接使用 Windows Python 主力版：

1. 進入 windows/python/ 目錄。
2. 第一次執行：雙擊 setup_venv.bat 自動建立環境與安裝套件。
3. 日常啟動：雙擊 start_pet.bat 即可在螢幕上看到小傢伙開始值班。

詳細操作與自訂說明請參閱 [windows/python/README.md](windows/python/README.md)。

## 金鑰安全

所有 API 金鑰均透過 Windows DPAPI 在本機端密文加密儲存，絕不上傳任何第三方伺服器，請放心玩耍。
