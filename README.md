# Desktop Pet（桌面寵物）

Desktop Pet 是一款常駐於作業系統桌面的輕量級智慧互動寵物掛件。角色手持一塊高科技平板電腦，即時顯示多模型 AI 的 API 帳戶餘額與消耗狀況。

當 API 產生調用並產生費用時，寵物會產生即時受擊震動、畫面紅閃與浮動扣款字樣；當帳戶充值時，畫面上會掉落米飯盆，將其拖曳餵食即可完成入帳。本專案具備完整的物理剛體碰撞、摸頭互動、鐵盆扣頭、智慧邊緣吸附與轉向、圖形化控制台以及本機 Web 伺服器 API 介面。

---

## 核心特色

### 1. 多模型 API 餘額即時監控
- 支援主流大型語言模型服務商：
  - DeepSeek：透過官方餘額查詢介面，即時讀取帳戶真實可用餘額（人民幣 CNY）。
  - Anthropic Claude：支援 Admin API Key，透過官方花費報表（cost_report）與起始額度計算即時剩餘費用（美元 USD）。
  - OpenAI：支援 Admin API Key，透過官方使用量報表與起始額度計算剩餘金額（美元 USD）。
  - Google Gemini：支援 API Key 設定與連線狀態顯示。
- 內建完整模擬模式（Simulation Mode）：
  - 不需填寫 API Key 即可完整體驗所有功能。
  - 支援手動或自動扣款（-0.01 / -0.10）、模擬充值（+3.00 掉落飯盆），並即時統計「今日已用」與「今日充值」。

### 2. 實時消耗動態扣款與表情切換
- 即時動態扣款反饋：餘額每消耗 0.01 元，寵物立刻觸發受擊紅閃、畫面微震、飄出浮動扣款數值，並伴隨打擊提示音效。
- 四態表情自動流轉：
  - 開心：平時常駐之預設狀態。
  - 緊張：餘額扣款受擊時觸發，扣款結束後維持 1 秒以平復情緒。
  - 傲嬌：米飯盆掉落於桌面超過 10 秒尚未餵食時觸發。
  - 冷漠：鐵盆扣在頭頂時觸發；此時即使產生扣款亦維持冷臉。

### 3. 豐富物理與道具互動
- 摸頭互動（Head Petting）：滑鼠游標在寵物頭部區域來回劃動時，觸發摸頭動畫，頭頂產生彈性微壓、冒出粉紅愛心並切換為緊張羞澀表情。若頭部扣有鐵盆，鐵盆具有防護效果，摸頭將直接不觸發。
- 餵食米飯盆：帳戶充值或模擬充值時，螢幕右側掉落米飯盆道具。將米飯盆拖曳至寵物身上即可完成餵食，金額一次性入帳、頭頂冒出愛心，並在原地彈出一個空鐵盆。
- 鐵盆扣頭與摘除：吃完米飯盆後留下的空鐵盆可任意拖曳，拖曳至寵物頭部放開即可扣在頭上；寵物表情轉為冷臉。在寵物頭部雙擊滑鼠左鍵，即可將鐵盆彈開摘除，恢復原本表情。
- 道具剛體碰撞物理：場上同時存在多個飯盆或鐵盆時，具備真實圓形剛體碰撞、彈性衝量與分離位移演算法，道具彼此推擠彈開，不會重疊雜亂。
- 火控雷達與自動吸食：米飯盆掉落於桌面超過 10 秒未被餵食時，自動開啟火控雷達鎖定標記（顯示方位、距離與動態瞄準框），並在 1 秒後產生引力將飯盆吸入寵物體內自動完成餵食入帳。

### 4. 邊緣自動吸附與轉向鏡像
- 智慧邊緣貼靠：拖曳寵物釋放後，若靠近螢幕邊緣即平滑緩動貼靠螢幕邊界。
- 轉向鏡像翻轉：當寵物貼靠螢幕右側邊緣或角落時，寵物立繪自動水平翻轉鏡像朝向內側；平板螢幕上的數字與文字透過智慧透視校正，始終保持正向且從左至右易讀。

### 5. 控制台與 Web 伺服器 API
- 完整圖形控制台：提供視窗設定（穿透、置頂、不透明度、尺寸、主題）、角色切換、音效庫、多廠商 API 配置與模擬測試。
- 本機 Loopback Web 伺服器：預設監聽 127.0.0.1:8765，提供精美視覺化網頁儀表板（含 SVG 餘額歷史曲線、當日用量統計、遠端操作按鈕）與標準 REST API（/api/state, /history.csv 等）。

### 6. 多樣化角色與自訂擴充
- 內建四大主流角色：DeepSeek 藍色大肥魚、Claude 大小姐、Gemini 祈願神龍、GPT 龍娘。
- 雙形態支援：正方形無尾巴（1024x1024, 1:1）與帶尾巴立繪（1536x1024, 1.5:1），透視螢幕座標自適應對齊。
- 自訂角色擴充：支援使用者自訂匯入立繪圖片與表情差分。
- 多寵物同時常駐：支援在桌面同時召喚最多 4 隻寵物，各自獨立監控所屬 AI 餘額。

### 7. 企業級金鑰安全與多 Key 自動備援輪替
- 原生 DPAPI 密文加密：API 金鑰絕不以明文儲存於設定檔，透過 Windows 原生 DPAPI 加密為密文。
- 多 API Key 自動輪替重試：各廠商支援多組金鑰輸入，遭遇 429 速率限制或 401 錯誤時自動輪替下一組重試。
- Windows 原生 PIN / 密碼身分驗證：可啟用 Windows 憑證防護，檢視或修改金鑰前必須通過本機身分驗證。

### 8. 極簡膠囊對話視窗與動態對話氣泡
- 參考現代簡潔設計，移除繁雜分頁，採用深灰圓角膠囊對話容器。
- 支援動態模型切換、語音輸入與模式切換，AI 回覆訊息同步於寵物頭頂飄出即時動態氣泡。

### 9. 雙模式自訂字體系統與現代化標題列
- 支援模式一系統字體選取與模式二 TTF/OTF 自訂字體匯入，即時套用全域介面。
- 整合自訂無邊框拖曳標題列與關閉控制，徹底解決視窗標題列反白無法關閉的問題。
- 全面整合 Google Material Symbols 開源向量圖示（Apache 2.0 協議），介面 100% 無 Emoji。

## 目錄結構與多平台支援

本專案支援多種平台與實作方式，整體目錄結構劃分如下：

```
deskop-pet/
├── README.md                      # 專案總覽文件（本文件）
├── windows/                       # Windows 平台實作
│   ├── README.md                  # Windows 平台版本總覽與對比說明
│   ├── python/                    # Python 全面重構主力版本（基於 PySide6）
│   └── powershell/                # PowerShell 歷史參考版本（免安裝腳本版）
├── dsh-balance-pet-macos/         # macOS 平台原生版本（基於 Swift + AppKit）
└── integration/                   # 網頁獨立嵌入版組件（適用於自建網站或監控面板）
```

### 多平台版本說明

1. Windows 版本 (`windows/`)
   - Python 版（`windows/python/`）：採用 Python 3.10+ 與 PySide6 (Qt for Python) 構建的全面重構主力版本。具備底層硬體繪圖加速、閒置零 CPU 佔用、完整的飯盆剛體碰撞物理、修復摸頭互動、雙形態立繪適配、7 分頁圖形控制台以及本機 Web API 伺服器，為 Windows 平台的推薦主力版本。
   - PowerShell 版（`windows/powershell/`）：採用 PowerShell 5.1 內嵌 C# WinForms 的歷史版本。無需安裝額外 Python 環境即可直接執行，保留作為歷史參考與備用方案。

2. macOS 版本 (`dsh-balance-pet-macos/`)
   - 採用 Swift 與 AppKit 原生打造的 macOS 版本。
   - 支援四角色切換、多表情差分、餵飯與疊盆、火控雷達、五幀懸停劃動摸頭、Dock 避讓適配與自動回位。支援 macOS 13 以上系統（Universal 二進位檔相容 Apple Silicon 與 Intel 架構）。

3. 網頁獨立嵌入版 (`integration/`)
   - 提供純 JavaScript 的網頁組件，可將桌面寵物掛件直接嵌入個人網站、導航頁或監控儀表板中。
   - 具備滑鼠與觸控拖曳、餵食、鐵盆、火控雷達與扣款動畫，可搭配獨立的後端餘額同步服務。
