# Desktop Pet（桌面寵物）

Desktop Pet 是一款常駐於桌面的餘額監控與互動寵物掛件。角色手持平板，顯示 AI 模型 API 帳戶餘額與使用狀況。

當 API 產生調用扣款時，寵物會產生受擊震動與浮動扣款提示；當帳戶充值時，畫面上會掉落米飯盆，拖曳餵食即可入帳。支援摸頭互動、鐵盆扣頭、邊緣吸附與轉向、圖形化控制台以及本機 Web 伺服器 API。

---

## 核心功能

### 1. 多模型 API 餘額監控
- 支援主流大型語言模型服務商：
  - DeepSeek：讀取官方帳戶可用餘額（人民幣 CNY）。
  - Anthropic Claude：支援 Admin API Key，計算即時剩餘費用（美元 USD）。
  - OpenAI：支援 Admin API Key，計算剩餘金額（美元 USD）。
  - Google Gemini：支援 API Key 設定與連線狀態顯示。
- 內建模擬模式（Simulation Mode）：
  - 不需填寫 API Key 即可體驗各項互動功能。
  - 支援手動或自動扣款（-0.01 / -0.10）、模擬充值（+3.00 掉落飯盆），並統計「今日已用」與「今日充值」。

### 2. 實時消耗扣款與表情切換
- 動態扣款反饋：餘額變動時觸發受擊紅閃、畫面微震與浮動數值。
- 四態表情切換：
  - 開心：平時常駐之預設狀態。
  - 緊張：餘額扣款受擊時觸發。
  - 傲嬌：米飯盆掉落於桌面超過 10 秒尚未餵食時觸發。
  - 冷漠：鐵盆扣在頭頂時觸發。

### 3. 道具與物理互動
- 摸頭互動：滑鼠游標在寵物頭部區域劃動時觸發摸頭動畫與愛心。若頭頂扣有鐵盆，鐵盆具備防護效果，摸頭不觸發。
- 餵食米飯盆：帳戶充值時掉落米飯盆，拖曳至寵物身上完成餵食，金額入帳並彈出空鐵盆。
- 鐵盆扣頭與摘除：空鐵盆可拖曳扣在寵物頭頂；雙擊寵物頭部即可取下鐵盆。
- 道具剛體碰撞：場上多個飯盆或鐵盆具備碰撞推擠，避免重疊。
- 火控雷達自動吸食：米飯盆掉落超過 10 秒未餵食時，可自動鎖定並吸入完成餵食。

### 4. 邊緣吸附與轉向鏡像
- 邊緣貼靠：拖曳釋放後靠近螢幕邊緣即平滑貼靠。
- 轉向鏡像：貼靠螢幕右側邊緣時，寵物立繪水平鏡像朝向內側；平板畫面自動透視校正，文字保持正向易讀。

### 5. 控制台與本機 Web 服務
- 圖形控制台：提供視窗設定、角色切換、音效庫、API 設定、自訂字體與日誌檢視。
- 本機 Web 伺服器：預設監聽 127.0.0.1:8765，提供網頁儀表板與 REST API（/api/state, /history.csv 等）。

### 6. 多角色與形態支援
- 內建角色：DeepSeek、Claude、Gemini、GPT。
- 雙形態支援：正方形（1024x1024）與帶尾巴立繪（1536x1024），平板座標自適應對齊。
- 自訂角色：支援使用者匯入自訂立繪圖片與表情差分。
- 多寵物同時常駐：可在桌面召喚多隻寵物同時運作。

### 7. 本機金鑰加密與多 Key 自動輪替
- DPAPI 密文加密：API 金鑰透過 Windows DPAPI 加密儲存，不以明文留存於設定檔。
- 多 API Key 自動輪替：各廠商支援設定多組金鑰，遭遇 429 或 401 錯誤時自動輪替下一組重試。
- Windows 身分驗證：可開啟憑證防護，檢視或修改金鑰前調用本機 PIN 或密碼驗證。

### 8. 對話視窗與動態對話氣泡
- 簡潔對話視窗，支援模型切換與語音輸入，AI 回覆同步顯示於寵物頭頂對話氣泡。

### 9. 雙模式自訂字體與無邊框標題列
- 支援本機系統字體選取與 TTF/OTF 自訂字體匯入。
- 視窗採用自訂標題列，具備拖曳、最小化與關閉控制。
- 採用 Google Material Symbols 向量圖示（Apache 2.0 協議），介面無 Emoji。

## 目錄結構與多平台支援

本專案支援多種平台與實作方式，整體目錄結構劃分如下：

```
deskop-pet/
├── README.md                      # 專案總覽文件（本文件）
├── windows/                       # Windows 平台實作
│   ├── README.md                  # Windows 平台版本總覽與對比說明
│   ├── python/                    # Python 全面重構主力版本（基於 PySide6）
│   └── powershell/                # PowerShell 歷史參考版本（免安裝腳本版）
├── dsh-balance-pet-macos/         # macOS 平台原生版本（基於 Swift + AppKit）
└── integration/                   # 網頁獨立嵌入版組件（適用於自建網站或監控面板）
```

### 多平台版本說明

1. Windows 版本 (`windows/`)
   - Python 版（`windows/python/`）：採用 Python 3.10+ 與 PySide6 (Qt for Python) 構建的全面重構主力版本。具備底層硬體繪圖加速、閒置零 CPU 佔用、完整的飯盆剛體碰撞物理、修復摸頭互動、雙形態立繪適配、7 分頁圖形控制台以及本機 Web API 伺服器，為 Windows 平台的推薦主力版本。
   - PowerShell 版（`windows/powershell/`）：採用 PowerShell 5.1 內嵌 C# WinForms 的歷史版本。無需安裝額外 Python 環境即可直接執行，保留作為歷史參考與備用方案。

2. macOS 版本 (`dsh-balance-pet-macos/`)
   - 採用 Swift 與 AppKit 原生打造的 macOS 版本。
   - 支援四角色切換、多表情差分、餵飯與疊盆、火控雷達、五幀懸停劃動摸頭、Dock 避讓適配與自動回位。支援 macOS 13 以上系統（Universal 二進位檔相容 Apple Silicon 與 Intel 架構）。

3. 網頁獨立嵌入版 (`integration/`)
   - 提供純 JavaScript 的網頁組件，可將桌面寵物掛件直接嵌入個人網站、導航頁或監控儀表板中。
   - 具備滑鼠與觸控拖曳、餵食、鐵盆、火控雷達與扣款動畫，可搭配獨立的後端餘額同步服務。
