# Desktop Pet（桌面寵物）— Windows 平台指南

本目錄提供 Windows 作業系統下的 Desktop Pet（桌面寵物）實作方案。目前包含兩個版本：歷史參考的 **PowerShell 版** 與全新現代化重構的 **Python 版**。

---

## 版本總覽

在 Windows 平台上，本專案歷經架構升級，為不同使用需求提供以下兩種版本：

### 1. Python 重構主力版 (`windows/python/`)
- 定位：推薦全體使用者與開發者採用的現代化主力版本。
- 技術棧：Python 3.10+、PySide6 (Qt for Python)、Windows Win32 API 封裝。
- 特色與優勢：
  - 低閒置負載：採用 Qt 圖形渲染架構，動畫閒置時計時器休眠。
  - 多模型支援：整合 DeepSeek、OpenAI、Anthropic Claude、Google Gemini，支援真實 API 查詢與模擬模式。
  - 物理與互動：
    - 支援滑鼠摸頭撫摸互動，具備擠壓變形與表情切換。
    - 飯盆具備剛體碰撞與推擠，多個飯盆推擠分離不重疊。
    - 鐵盆扣頭防護機制（扣頭時不觸發摸頭，雙擊頭部取下）。
    - 邊緣貼靠與右側邊界水平鏡像翻轉，平板文字自動校正。
  - 雙形態立繪適配：支援 1024x1024 正方形（1:1）與 1536x1024 帶尾巴（1.5:1）立繪規格，平板座標自適應。
  - 控制台與 Web 伺服器：提供視覺化控制台，內建本機 Web 伺服器（預設監聽 127.0.0.1:8765），支援 SVG 走勢圖、歷史記錄 CSV 匯出與 REST API。
  - 本機金鑰安全：支援 Windows DPAPI 密文加密儲存、多 API Key 自動輪替重試（401/429）與本機 PIN / 憑證身分驗證。
  - 簡潔對話視窗：支援模型切換、語音輸入與頭頂動態對話氣泡。
  - 雙模式自訂字體與無邊框標題列：支援系統字型選取與 TTF/OTF 自訂匯入，視窗標題列具備拖曳與關閉控制。
  - Google Material Symbols：採用開源向量圖示庫，介面無 Emoji。
  - 多寵物同時常駐：支援在桌面召喚多隻餘額寵物獨立運作。
  - 歷史版本對照：舊版 Python 程式碼保留於 `windows/python_old/`。

### 2. PowerShell 歷史參考版 (`windows/powershell/`)
- 定位：歷史參考版本、無 Python 環境下的即開即用備用方案。
- 技術棧：Windows PowerShell 5.1 + 內嵌 C# 編譯 + Windows Forms。
- 特點與限制：
  - 免安裝執行：依賴 Windows 系統內建的 PowerShell 5.1 與 .NET 執行環境，雙擊指令檔即可直接執行，無需安裝額外軟體。
  - 歷史全功能驗證：已包含角色手持平板、扣款受擊震動、充值掉落飯盆、鐵盆扣頭、火控雷達與多模型切換的原型功能。
  - 架構局限性：由於採用 WinForms 逐像素透明與 GDI+ 繪圖機制，在連續扣款、頻繁切換表情或視窗動畫時，CPU 與記憶體佔用較高，偶有滑鼠發黏現象，且道具重疊物理較為簡單。

| **後續維護** | 持續維護與功能擴充主力 | 封存維護，僅供歷史參考 |

## 使用方式與選擇建議

### 選擇建議
1. 強烈建議使用 Python 版：
   - 無論是日常桌面常駐、多模型餘額監控、自訂角色匯入，還是追求極致順暢的物理互動動畫，Python 版均為最佳選擇。
   - 透過專案提供的自動化批次檔，可一鍵建立虛擬環境與安裝依賴，使用門檻極低。
2. PowerShell 版之適用情境：
   - 僅適合於無法安裝 Python 環境、受限的受管電腦，或是希望快速瀏覽本專案早期實作邏輯時使用。

### 快速開始指南

#### 使用 Python 版（推薦主力）
1. 進入 `windows/python/` 目錄。
2. 首次執行：雙擊 `setup_venv.bat`，系統將自動建立虛擬環境並安裝所需依賴（PySide6 等）。
3. 日常啟動：雙擊 `start_pet.bat`，即可靜默無黑窗啟動桌面寵物。
4. 詳細安裝設定、指令參數與模組架構，請參閱 [windows/python/README.md](python/README.md)。

#### 使用 PowerShell 版（歷史備用）
1. 進入 `windows/powershell/` 目錄。
2. 雙擊 `start_pet.vbs` 啟動寵物（若有安全性防護攔截，可改為執行 `start_pet_debug.bat`）。
3. 首次啟動依提示設定 API Key，或右鍵點擊寵物開啟選單進行操作。
4. 詳細說明請參閱 `windows/powershell/` 目錄內之說明文件。
