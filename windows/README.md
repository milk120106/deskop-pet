# Desktop Pet — Windows 平台指南

本目錄提供 Windows 系統專屬的螢幕浮動小掛件。這是一個做來放鬆與玩耍的趣味專案，讓可愛的小傢伙停在工作列或螢幕邊緣，一邊陪你用電腦，一邊幫你注意 API 餘額。

---

## 怎麼玩

- 盯緊餘額防破產：小傢伙手持的小平板會即時顯示 API 餘額。調用扣款時小傢伙會挨揍晃動並冒出扣款提示；帳戶充值時，米飯盆會從螢幕上方掉落，用滑鼠拖曳到牠身上就能餵食入帳。
- 摸頭撫摸與鐵盆防禦：滑鼠游標在頭部來回滑動可以摸摸頭，小傢伙會害羞冒愛心；吃完飯留下的空鐵盆，可以拖到頭上當安全帽扣著，扣上後表情瞬間變冷漠且摸頭無效，連點兩下頭部就能把鐵盆彈開摘下。
- 語音吐槽閒聊：點開對話視窗即可用文字或語音跟牠對話，AI 回覆會以對話氣泡動態出現在小傢伙頭上。
- 貼邊轉向與自由換裝：拖動小傢伙靠近螢幕兩側會滑順吸附貼邊，靠右側時會自動鏡像轉向，且平板文字自動校正保持正向；支援切換多款內建角色或匯入自訂立繪。

## 版本介紹與怎麼跑起來

這裡提供了兩個版本，推薦使用功能最完整的 Python 版：

### 1. Python 重構主力版（推薦）
- 位置：windows/python/
- 特點：採用 PySide6 打造，畫面細緻滑順、閒置時幾乎零 CPU 佔用，具備完整的飯盆剛體碰撞、控制台與本機 Web 儀表板。
- 快速開始：
  1. 進入 windows/python/ 目錄。
  2. 首次執行請雙擊 setup_venv.bat（自動建置虛擬環境與安裝依賴）。
  3. 日常啟動雙擊 start_pet.bat 即可無黑窗靜默執行。
  4. 完整設定與進階功能請見 [windows/python/README.md](python/README.md)。

### 2. PowerShell 歷史版（備用）
- 位置：windows/powershell/
- 特點：依賴 Windows 內建環境，免安裝 Python 即可直接執行，適合受限環境或快速體驗早期原型。
- 啟動方式：進入 windows/powershell/ 目錄，雙擊 start_pet.vbs 即可啟動。

## 金鑰安全

所有 API 金鑰均採用 Windows 原生 DPAPI 於本機密文加密儲存，支援多組 Key 自動輪替與 PIN 碼保護，絕不對外上傳任何私密金鑰。
