# Desktop Pet — Python / PySide6 重構版

這是 Windows 平台的主力版本，基於 Python 3.10+ 與 PySide6 打造。

純粹做來玩、圖個開心的小掛件，透明浮動在螢幕角落，停靠於工作列或螢幕邊緣陪你寫代碼。具備硬體繪圖加速與零閒置 CPU 負擔，平時安心常駐，無聊時隨手戳戳互動。

---

## 怎麼玩（操作指南）

- 看緊餘額：小平板即時顯示當前 API 餘額（支援 DeepSeek、Claude、OpenAI、Gemini，也提供不用填 Key 的模擬模式）。扣款時小傢伙會挨揍受擊晃動；充值時米飯盆會從螢幕上方掉落下來，拖曳到牠身上即可餵食入帳（若放置超過 10 秒，牠還會開啟火控雷達自動吸食）。
- 摸摸頭：滑鼠游標在小傢伙頭部區域來回劃動，能觸發摸頭擠壓彈性動畫與冒愛心。
- 鐵盆安全帽：餵食後彈出的空鐵盆，可以用滑鼠拖到頭頂扣上當防護盔。戴上後表情切換為冷臉且摸頭無效；對著頭部快速連點兩下（雙擊）即可將鐵盆彈開取下。
- 雙擊平板翻頁：連點兩下小平板螢幕，可切換查看即時餘額或今日累積花費統計。
- 語音閒聊吐槽：開啟簡約膠囊對話視窗，支援語音與文字輸入，AI 回覆會直接以頭頂動態氣泡呈現。
- 自動貼邊與轉向：拖曳放開後自動滑順吸附螢幕邊緣；貼靠螢幕右側時立繪自動水平翻轉面向螢幕內側，且平板文字自動校正為正向易讀。
- 控制台設定：滑鼠右鍵點擊寵物或系統工作列托盤圖示，可喚出控制台，支援切換立繪角色、調整尺寸與透明度、匯入自訂立繪與音效、切換模擬模式，或是打開本機 Web 儀表板（預設 127.0.0.1:8765）。

## 怎麼跑起來（快速開始）

環境要求：Windows 10 / 11（64 位元），已安裝 Python 3.10 或更高版本。

### 1. 一鍵批次檔（推薦）
- 首次安裝環境：雙擊執行 setup_venv.bat（自動建立虛擬環境並安裝所需依賴）。
- 日常啟動：雙擊執行 start_pet.bat（無終端黑窗，背景靜默啟動）。
- 除錯模式：雙擊執行 start_pet_debug.bat（保留命令列視窗，方便檢視 Log）。

### 2. 命令列啟動
啟動虛擬環境或在終端機中執行：
```cmd
python main.py
```

常用啟動參數：
- 執行全自動功能檢查：`python main.py --selftest`
- 開發模式（允許開多隻寵物並輸出 Log）：`python main.py --dev`
- 自訂 Web 伺服器通訊埠：`python main.py --port 8888`

## 自訂角色簡介

想換成自己喜歡的角色？只需在 `custom_characters/<角色名稱>/` 資料夾內放入圖片即可：
- `sprite.png`：主立繪影像（透明背景 PNG 最佳，支援 1024x1024 緊湊立繪或 1536x1024 帶尾巴立繪）。
- `tablet.txt`（選填）：平板在立繪上的透視四角座標（未提供時系統自動置中）。
- `sprites/`（選填）：放置開心（expression_11.png）、冷臉（expression_12.png）、緊張（expression_21.png）、傲嬌（expression_22.png）等表情差分。

## 金鑰安全

所有 API 金鑰均使用 Windows DPAPI 本機密文加密儲存，可選用 Windows PIN 碼身分驗證防護，金鑰絕不上傳第三方伺服器，安心守護荷包。
