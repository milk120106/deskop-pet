# Desktop Pet（桌面寵物）— Python / PySide6 重構版

以 PySide6 (Qt for Python) 完整重構的多角色桌面餘額與互動寵物，具備硬體繪圖加速與零閒置 CPU 佔用架構，完整實作多模型監控、道具物理碰撞、摸頭互動、鐵盆扣頭、智慧邊緣吸附與本機 Web 服務。

---

## 環境要求

- 作業系統：Windows 10 / 11（64 位元）
- Python 版本：Python 3.10 或更高版本
- 依賴套件：PySide6（Qt 6）、Requests、urllib3 等（詳見 requirements.txt）

---

## 啟動方式

專案根目錄已提供一鍵設定與啟動指令檔，建議透過內建批次檔操作：

### 1. 批次檔啟動

- 首次啟動（自動建置虛擬環境並安裝依賴）：
  執行 `setup_venv.bat`
- 日常啟動（無黑窗背景靜默執行）：
  執行 `start_pet.bat`
- 除錯模式啟動（保留終端機主控台輸出，方便即時檢視 Log）：
  執行 `start_pet_debug.bat`

### 2. 命令列與參數啟動

於虛擬環境或已配置 Python 3.10+ 的環境中執行 `main.py`，支援以下啟動參數：

- 標準啟動（具備單一實例互斥鎖，避免重複執行）：
  ```cmd
  python main.py
  ```

- 執行全自動自我檢查（Self-Test）：
  程式內建完整 headless / live 視覺與邏輯自我驗證套件，自動測試 46 項功能斷言並輸出檢驗截圖至 `selftest_out/`：
  ```cmd
  python main.py --selftest
  ```

- 開發模式啟動（--dev）：
  略過單一實例互斥鎖，允許同時開啟多個寵物實例，並於終端輸出詳細除錯訊息：
  ```cmd
  python main.py --dev
  ```

- 自訂本機 Web 伺服器通訊埠（--port）：
  指定本機 Web 伺服器監聽通訊埠（預設為 8765，若遇佔用將自動向後順延）：
  ```cmd
  python main.py --port 8888
  ```

## 系統模組架構說明

本程式採用模組化架構設計，各模組職責清晰、高內聚低耦合：

```
windows/python/
├── main.py                      # 程式主入口（參數解析、單一實例互斥鎖、生命週期）
├── requirements.txt             # 依賴套件清單
├── setup_venv.bat               # 虛擬環境自動建立批次檔
├── start_pet.bat                # 靜默啟動批次檔
├── start_pet_debug.bat          # 除錯啟動批次檔
├── deskpet/
│   ├── app.py                   # 應用程式控制器（App），協調整合視窗、托盤、選單與伺服器
│   ├── pet.py                   # 寵物主視窗（PetWindow），渲染、透視平板、摸頭、表情流轉
│   ├── panel.py                 # 7 大分頁控制台（ControlPanel），全功能參數設定
│   ├── props.py                 # 道具物理引擎（PropsManager / RiceBowl / IronBowl），剛體碰撞與火控
│   ├── balance.py               # 帳本與多模型餘額查詢（Ledger），API 輪詢與模擬帳目
│   ├── web.py                   # 本機 Web 伺服器（WebServer），提供儀表板與 REST API
│   ├── config.py                # 配置管理器（Config），JSON 持久化與舊版 INI 雙向相容
│   ├── audio.py                 # 音效模組（Sounds），4 槽位獨立音量控制與自訂音頻載入
│   ├── dialogs.py               # 獨立對話框（角色選擇器、自訂音效庫、Q 版角色管理器）
│   ├── winapi.py                # Windows 原生 Win32 API 封裝（穿透、無邊框置頂）
│   └── selftest.py              # 全自動單元與視覺功能自我檢驗套件
├── assets/                      # 內建角色立繪、表情差分、道具圖素與預設音效
├── custom_characters/           # 使用者匯入的自訂角色存放目錄
├── custom_q/                    # 使用者匯入的自訂 Q 版角色存放目錄
└── custom_sounds/               # 使用者自訂提示音存放目錄
```

### 核心模組職責詳解

1. `deskpet/app.py`（應用程式控制器 App）：
   - 管理整體生命週期，建立並維護系統托盤圖示與全功能右鍵選單。
   - 協調寵物主視窗、控制台、音效池、帳本與 Web 伺服器之間的訊號通訊。
2. `deskpet/pet.py`（寵物主視窗 PetWindow）：
   - 繪製寵物本體與手持透視平板螢幕，支援平滑雙線性插值與點陣快取，零動畫時完全休眠。
   - 實作智慧邊緣吸附、右側邊界水平鏡像翻轉（文字反向校正保持可讀）。
   - 實作摸頭撫摸互動（滑鼠劃動彈性擠壓、冒愛心、緊張表情）。
   - 實作鐵盆扣頭防護邏輯（扣頭時冷漠表情、免疫摸頭、雙擊頭部摘下彈開）。
3. `deskpet/panel.py`（控制台 ControlPanel）：
   - 7 大分頁圖形介面：視窗、角色、Q 版角色、演示、聲音、餘額與廠商、網頁面板。
4. `deskpet/props.py`（道具物理引擎 PropsManager）：
   - 管理米飯盆與空鐵盆的重力掉落與桌面彈跳。
   - 實作真實圓形剛體碰撞與彈性衝量分離演算法，道具重疊時自動排斥彈開。
   - 實作米飯盆停留 10 秒啟動火控雷達鎖定標記，並產生引力自動吸入餵食。
5. `deskpet/balance.py`（帳本與餘額 Ledger）：
   - 管理即時餘額顯示值、真實可用值、最近 300 筆事件紀錄清單。
   - 支援 DeepSeek（官方餘額）、Anthropic Claude（Admin Key 花費報表）、OpenAI（Admin Key 使用量計算）與 Google Gemini。
   - 支援本機模擬模式（自由設定起始餘額、自訂扣款與充值、今日已用與充值統計）。
6. `deskpet/web.py`（本機 Web 伺服器 WebServer）：
   - 監聽 127.0.0.1 環回介面，提供即時 SVG 走勢儀表板與 RESTful API。
7. `deskpet/config.py`（配置管理器 Config）：
   - 統一管理 `pet_config.json`，並自動讀寫與相容 `provider.ini`、`usage.ini` 與 `character.txt`。
8. `deskpet/winapi.py`（Windows API 封裝）：
   - 封裝 `user32.dll` 與 `dwmapi.dll`，動態切換滑鼠穿透（`WS_EX_TRANSPARENT`）與無邊框視窗分層渲染。

## 角色圖片規格規範

本專案支援多種立繪形態與使用者自訂角色匯入，相關規格說明如下：

### 1. 正方形無尾巴立繪規格（Square Variant）
- 影像解析度：1024x1024 像素（寬高比 1:1）。
- 影像格式：32 位元透明 PNG（RGBA）。
- 特點說明：適用於身形緊湊、無大面積橫向外延尾巴之角色。平板螢幕透視座標預設對齊於立繪正下方雙手持握區域。

### 2. 帶尾巴立繪規格（Tail Variant）
- 影像解析度：1536x1024 像素（寬高比 1.5:1）。
- 影像格式：32 位元透明 PNG（RGBA）。
- 特點說明：專為具備橫向飄逸大尾巴或寬幅構圖的角色設計。系統會自動擴展渲染畫布寬度，並依比例自適應重新計算平板透視四角座標，確保平板位置精準無誤。

### 3. 自訂角色匯入規範
使用者可匯入自己繪製或喜愛的角色立繪，規範如下：
- 目錄結構：放置於 `windows/python/custom_characters/<角色名稱>/`。
- 必要檔案：
  - `sprite.png`：主立繪影像（透明 PNG 最佳，亦相容 JPG 與 WEBP）。
  - `tablet.txt`：平板螢幕四角座標定義檔。純文字格式，內含 8 個以空白分隔的整數，依序代表左上X、左上Y、右上X、右上Y、右下X、右下Y、左下X、左下Y（以 1024x1024 座標系為基準）。若未提供，系統預設將平板配置於角色下方居中位置。
- 選擇性表情差分：放置於該角色目錄下的 `sprites/` 子資料夾：
  - `expression_11.png`：開心表情（預設狀態）
  - `expression_12.png`：冷臉表情（鐵盆扣頭）
  - `expression_21.png`：緊張表情（扣款受擊）
  - `expression_22.png`：傲嬌表情（飯盆逾時未餵食）
  - 差分圖片解析度與畫布需與主立繪 `sprite.png` 完全一致。若未提供差分，系統將以主立繪常駐渲染。

### 4. 暫時未完成之 Q 版角色說明
- 模組設計：架構中已於 `deskpet/qchars.py` 完成 Q 版桌面小人的漫遊物理運算（自主隨機遊走、螢幕邊界碰撞反彈、重力下落）。
- 黑化模式限制：黑化模式（Dark Mode）嚴格限定於 DeepSeek Q 版角色（因為僅 DS Q 版具有黑化專屬設計圖素，其他廠商角色與常駐大寵物皆不具有黑化模式，大寵物絕不會跟著黑化）。
- 官方圖素進度說明：目前官方內建之 Q 版角色美術圖素正在重新繪製整理中，在控制台中點擊召喚內建 Q 版角色將提示該功能暫未開放。
- 自訂 Q 版體驗：使用者現階段可透過控制台的「匯入自訂 Q 版」功能匯入自己喜愛的圖片（支援 PNG/JPG/WEBP，限制檔案大小 10MB 內、解析度 2048px 內）加入漫遊佇列，搶先體驗桌面遊走互動。

## 操作指南

| 動作 | 效果說明 |
| :--- | :--- |
| **滑鼠左鍵拖曳寵物** | 移動寵物位置；拖曳中靠近兩側會即時轉向；放開時若開啟自動貼邊則平滑貼邊 |
| **滑鼠右鍵點擊寵物** | 開啟完整功能選單（控制台、角色選擇、音效庫、網頁面板、滑鼠穿透、貼邊、演示等） |
| **滑鼠在頭部來回撫摸** | 來回劃動觸發摸頭動畫（頭部彈性壓縮、冒出愛心、緊張表情）；**鐵盆扣在頭上時直接不觸發** |
| **雙擊寵物平板** | 切換平板螢幕：第 0 頁（即時餘額） ⇄ 第 1 頁（DeepSeek 梁文峰/梁文谷倒數 或 廠商時間與今日花費） |
| **雙擊寵物頭部** | 當頭上扣著鐵盆時，將鐵盆彈開摘下並播放取下音效 |
| **雙擊系統托盤圖示** | 喚出控制台視窗；托盤選單可隨時解除滑鼠穿透模式 |
| **拖曳飯盆餵食** | 將掉落的飯盆拖曳至寵物身上餵食：金額一次性入帳、愛心飄起、原地彈出空鐵盆 |
| **拖曳鐵盆扣頭** | 將空鐵盆拖曳至寵物頭部釋放：鐵盆扣在頭上，寵物表情轉為冷臉且免疫摸頭 |
| **飯盆停留超過 10 秒** | 自動啟動火控雷達鎖定標記，1 秒後強烈吸引進寵物體內自動完成餵食入帳 |

## 控制台（7 大分頁）

透過寵物右鍵選單、托盤選單或網頁面板點擊「控制台」即可開啟：

1. **視窗**：滑鼠穿透開關、自動貼邊開關、貼邊觸發距離、回到螢幕角落、視窗置頂開關、視窗不透明度滑桿、寵物尺寸滑桿、深淺主題切換。
2. **角色**：切換正方形無尾巴（1024x1024）與帶尾巴立繪（1536x1024），開啟「角色選擇視窗」預覽或匯入自訂角色。
3. **Q 版角色**：黑化模式總開關（限 DS）、管理與匯入自訂 Q 版角色、清除所有場上 Q 版角色。
4. **演示**：模擬扣款 -0.01、模擬扣款 -0.10、模擬充值 +3.00（掉落米飯盆）、立即啟動火控雷達鎖定。
5. **聲音**：音效總開關、主音量滑桿、開啟「自訂音效庫視窗」（設定 4 個槽位獨立音量與替換自訂音頻）。
6. **餘額與廠商**：切換模擬模式 / API 模式、選擇廠商（DeepSeek / OpenAI / Claude / Gemini）、配置 API Key、查詢間隔與起始預算設定。
7. **網頁面板**：檢視目前本機網頁伺服器狀態與通訊埠，一鍵在預設瀏覽器中開啟視覺化網頁儀表板。

## 本機 Web API 端點說明

桌面寵物內建輕量本機 Web 伺服器，嚴格僅監聽於本機環回網路（`127.0.0.1`，預設通訊埠 `8765`），提供視覺化儀表板與標準 HTTP API 介面：

### 1. 頁面與資料端點

- `GET /` 或 `GET /index.html`
  - 說明：視覺化響應式網頁儀表板。
  - 內容：包含即時 SVG 餘額歷史走勢圖、今日已用與充值統計卡片、場上飯盆計數、最近 300 筆事件清單、近期日誌展示與遠端快捷控制按鈕。

- `GET /api/state`
  - 說明：取得寵物目前的即時執行狀態資料。
  - 格式：`application/json; charset=utf-8`
  - 回傳欄位說明：
    ```json
    {
      "mode": "sim",
      "provider": "DeepSeek",
      "currency": "CNY",
      "balance": 50.00,
      "connected": true,
      "error": "",
      "character": "deepseek",
      "todayUsed": 0.03,
      "todayTopUp": 3.00,
      "bowls": 1,
      "updated": "11:58:00",
      "events": [
        {"t": "10-24 11:57:30", "d": -0.01, "b": 49.99}
      ],
      "log": ["line 1", "line 2"]
    }
    ```

- `GET /history.csv`
  - 說明：匯出並下載 UTF-8 編碼之歷史帳目 CSV 檔案。
  - 格式：`text/csv; charset=utf-8`
  - 檔案標頭：`\ufefftime,delta,balance`

- `GET /sprite.png`
  - 說明：取得目前正在使用的角色立繪圖像。
  - 格式：`image/png`

### 2. 遠端控制端點

- `POST /feed`
  - 說明：遠端觸發餵食動作。若場上有米飯盆則直接完成餵食入帳並彈出空鐵盆；若場上無米飯盆則模擬充值入帳。
  - 回傳：`{"ok": true}`

- `POST /topup`
  - 說明：遠端觸發模擬充值 3.00，並在桌面掉落一個米飯盆。
  - 回傳：`{"ok": true}`

- `POST /api/action?name=<action_name>&token=<token>`
  - 說明：通用控制介面。
  - 支援的 `name` 動作名稱：
    - `refresh`：強制觸發線上 API 餘額重新整理。
    - `mode`：切換模擬模式（sim）與線上 API 模式（api）。
    - `charge1`：模擬消耗 0.01 元（觸發受擊動畫與音效）。
    - `charge10`：模擬消耗 0.10 元（觸發受擊動畫與音效）。
    - `topup`：模擬充值 3.00（掉落米飯盆）。
    - `feed`：遠端執行餵食入帳。
    - `clearbowls`：清除桌面所有米飯盆與空鐵盆。
  - 回傳：`{"ok": true}` 或 `{"ok": false, "error": "..."}`

## v2.1.0 更新內容

1. 金鑰安全防護（Windows DPAPI 與本機 PIN 驗證）
   - DPAPI 密文持久化：API 金鑰儲存至設定檔時透過 Windows DPAPI (CryptProtectData) 加密，不以明文留存。
   - Windows 原生 PIN / 密碼身分驗證：可開啟「要求 Windows 身分驗證」防護，檢視或修改金鑰前調用本機 PIN 或密碼驗證。
   - 密碼遮蔽顯示模式：提供 API Key 遮蔽開關，支援密碼隱藏（顯示為圓點）與切換檢視。

2. 多 API Key 自動備援輪替機制
   - 每個模型供應商支援配置多組 API Key（以逗號、分號或換行分隔輸入）。
   - 於對話或餘額查詢遭遇 429（額度超限/速率限制）或 401（未授權/失效）錯誤時，系統自動輪替至下一組備援金鑰重試。

3. 動態模型導向與線上探索
   - 模型預設指向最新動態別名：
     - Google Gemini：gemini-flash-latest、gemini-flash-lite-latest、gemini-pro-latest、gemini-3.8-live。
     - OpenAI：gpt-4o、gpt-4o-mini、o3-mini、o1。
     - Anthropic (Claude)：claude-3-5-sonnet-latest、claude-3-5-haiku-latest、claude-3-7-sonnet-latest。
     - DeepSeek：deepseek-chat（動態對齊 V3）、deepseek-reasoner（動態對齊 R1）。
   - 支援線上探測模型清單（discover_models），取得遠端支援模型。

4. 簡潔對話視窗與動態對話氣泡
   - 簡約對話介面，移除多餘分頁，採用深灰圓角膠囊容器。
   - 整合模型選擇、模式切換、語音輸入與發送按鈕。
   - AI 回覆訊息時同步在寵物頭頂上方顯示即時對話氣泡。

5. 雙模式自訂字體系統
   - 模式一：自動讀取本機系統字體清單，下拉即選即用。
   - 模式二：支援自訂匯入 .ttf / .otf / .ttc 字型檔案並動態載入。

6. 自訂視窗標題列
   - 控制台與彈窗採用自訂標題列（CustomTitleBar），提供最小化與關閉按鈕，解決視窗標題列在部分環境反白無法關閉的問題。

7. Google Material Symbols 開源圖示整合
   - 依據 Apache 2.0 協議整合 Google Material Symbols 向量圖示，介面無 Emoji。

8. 支援多隻餘額寵物同時常駐
   - 可在桌面召喚多隻寵物，各自獨立顯示即時餘額。
