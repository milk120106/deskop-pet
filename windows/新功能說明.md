# Windows 版更新說明

本版本暫時只維護 Windows 版；macOS 目錄保留原始內容，但不在本次更新範圍內。

## 本次修正

- **透明度**：右鍵選單可設定 15%–100%，設定會保存到 `state.ini`。
- **固定位置**：開啟後角色不會被拖動或自動吸回角落。
- **滑鼠穿透**：開啟後角色不攔截滑鼠點擊；可從系統匣／右鍵選單切回，或使用 `Ctrl+Alt+P` 快速切換。
- **走動模式**：角色會在底部小範圍來回移動；固定位置時會自動停用。
- **Q 版模式**：可從右鍵選單開關。若把自訂的 `chibi.png` 放在 `windows` 目錄，會優先使用該圖片；沒有時使用縮小透明 fallback。
- **火控延遲**：不再固定 10 秒，可設定 0.5–3600 秒。
- **愛心／浮動數字殘影**：動畫物件現在會加入上一幀清除範圍，角色移動或飛回角落後不會留下殘影。
- **角色切換**：改為同一個 PowerShell 程序內釋放舊圖片、載入新圖片、重建快取並立即重繪，不再開新程序，因此不會出現切換空白。
- **跨 DPI 尺寸**：舊版 `cm=8` 在高 DPI 電腦上可能變成很大的像素尺寸；新版本對舊的 `px=0` 狀態採用固定 454px 預設，避免不同電腦比例失控。尺寸選單仍可自行調整。
- **效能**：平常畫面保留合成節流以降低 CPU；拖曳、摸頭及互動時自動提高推送頻率，減少操作卡頓。

## 原有功能摘要

- 模擬／API 餘額模式與多廠商設定。
- 角色選擇、自訂角色、表情差分、平板面板、飯盆與火控雷達。
- 飯盆可拖曳餵食，也可清除；鐵盆可拖曳並扣在角色頭上。
- 網頁唯讀面板綁定 `127.0.0.1`，不對外開放。

## 注意

Windows 內嵌 C# 只能在 Windows PowerShell 5.1／WinForms 環境實際啟動測試。本次在 Linux 沙盒抽取內嵌 C# 並以 Mono 編譯通過；Windows 的 DPI、分層視窗與 UI Automation 行為仍應在實際 Windows 電腦確認。
