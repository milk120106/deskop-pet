# 新功能（模式切換 / 多廠商 / 網頁）

## 右鍵面板（或托盤右鍵選單）
- 模式：點一下在「模擬」與「API 餘額」之間切換，不用重啟，選擇會記在 provider.ini。
- API Key / 廠商設定：新視窗，上方選廠商，下面填 Key；OpenAI、Anthropic 另有「起始額度」與「起算日」。
- 角色：切換角色（會自動重啟）。
- 在網頁上查看餘額：用瀏覽器開 http://127.0.0.1:8765/（被佔用時自動往後找到 8775）。

## 各廠商
| 廠商 | 取得方式 | 需要的 Key |
|---|---|---|
| DeepSeek | 官方餘額介面，直接讀取（人民幣） | 一般 API Key |
| OpenAI | 沒有餘額介面，用花費報表：起始額度 − 起算日至今花費（美元），每 60 秒查一次 | Admin Key |
| Anthropic | 同上，用 cost_report | Admin Key（sk-ant-admin…） |
| Google Gemini | 官方沒有餘額/花費 API，無法取得，API 模式顯示未連線 | 僅保存 |

## 檔案
- provider.ini：模式、廠商、各廠商起始額度與起算日
- apikey.txt（DeepSeek）、apikey_openai.txt、apikey_anthropic.txt、apikey_gemini.txt：各家 Key，明文存放，請勿外流
- 網頁只綁定 127.0.0.1，唯讀，只能看不能改

## 第二批更新
- 角色：右鍵「角色」現在開選擇視窗（列表加預覽），可「新增自訂角色…」匯入任意圖片，也可刪除自訂角色。選好後程式會自動重啟套用。
  - 自訂角色存在 chars\custom_名稱\，裡面的 tablet.txt 是平板螢幕四個角（左上、右上、右下、左下，8 個數字，1024x1024 座標）。預設把螢幕畫在角色下方，圖片裡有拿平板的話請自己改成平板位置。
  - 想要表情變化，可在該資料夾放 sprites\expression_11/12/21/22.png（尺寸要和 sprite.png 相同），沒有就只用單張圖。
- 平板：只有藍色大肥魚顯示「梁文峰／距谷時」；其他角色顯示本機時間、模式或廠商、今日已用。
- 飯盆：縮小約三成（火控雷達跟著縮小）；右鍵點飯盆可清除（錢仍會入帳）；放著不管 45 秒自動清除；切換模式時會清掉場上的飯盆。
- 流暢度：換表情不再重配整張螢幕畫布，啟動時預先建好所有表情，並改為每幀都更新畫面；摸頭的手加快。
- 網頁：新增今日已用／充值、飯盆數、走勢最高最低、按鈕（立即刷新、切換模式、模擬扣款／充值、清除飯盆）、CSV 下載、執行記錄。
